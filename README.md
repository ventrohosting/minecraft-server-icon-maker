# Minecraft Server-Icon erstellen

Minecraft Server-Icon erstellen: Bild zuschneiden oder Schriftzug wählen, Vorschau in der Serverliste ansehen und server-icon.png mit 64 x 64 Pixeln speichern.

**Online nutzen:** [Minecraft Server-Icon erstellen](https://ventrohosting.com/tools/minecraft-server-icon) · Demo: https://ventrohosting.github.io/minecraft-server-icon-maker/

## Funktionen

- Bild zuschneiden oder Schriftzug mit Farbverlauf
- Vorschau wie in der Serverliste
- server-icon.png mit 64 × 64 Pixeln, das Bild verlässt den Browser nicht
